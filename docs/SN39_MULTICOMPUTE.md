# Retired SN39 multi-compute procedure

This page previously documented UID30-specific preview and one-shot
consolidation commands. Those commands are not installed or supported.

The supported path is the recurring direct validator on the
[repository home page](../README.md). It reads every serving miner, verifies
each signed fleet with the pinned QVL and SAT primitives, applies global
deduplication, and submits one locally derived weight vector.

The former procedure remains available in Git history for artifact recovery.
It is not current operating authority.
