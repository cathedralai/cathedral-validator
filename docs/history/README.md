# Historical record

These documents record release ceremonies, cutover windows, and one-off migrations as they happened.

Do not follow their **procedures** — they describe windows that have closed, and several name revisions the current tree no longer pins. Their **recorded data** is still authoritative and is cited from active docs: [`docs/PROVENANCE.md`](../PROVENANCE.md) reads the exact provenance pins out of [`SN39_MAINNET_RELEASE_20260724.md`](SN39_MAINNET_RELEASE_20260724.md), and those digests match the shipped config.

Public validator operation is not self-service during live testing. Do not use
these historical records as installation or operating instructions.
